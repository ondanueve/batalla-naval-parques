# Batalla Naval Parques

**🌐 Jugá ahora:** https://ondanueve.github.io/batalla-naval-parques/

**Batalla Naval modernizada** estilo RPG Pokémon, ambientada en los 3 Parques Nacionales Argentinos más populares:

- 🏞️ **Nahuel Huapi** (lagos, bosques, montañas)
- 🌿 **Iguazú** (selva, cataratas, niebla)
- ❄️ **Los Glaciares** (hielo, glaciares, picos)

## Características

- **1v1 PvP** (hotseat / turnos locales) y **PvC** (vs IA)
- Un jugador siempre es **Argentina** 🇦🇷
- El otro es el **Invasor**, a elegir entre: 🇨🇱 Chile, 🇬🇧 Reino Unido, 🇺🇸 EE.UU., 🇨🇳 China, 🇷🇺 Rusia, 🇧🇷 Brasil
- Mecánicas nuevas: poderes especiales (Radar, Bomba, Camuflaje), efectos ambientales por mapa, animaciones RPG
- Visualmente atractiva, colores vibrantes estilo Pokémon
- **Jukebox** copiado y adaptado de [choppy-bitcoin](https://github.com/ondanueve/choppy-bitcoin) (música ABC con ABCJS)

## Cómo jugar

1. Elegí el mapa (parque)
2. Elegí el modo: PvP o PvC
3. Elegí la nación invasora
4. Colocá tus barcos (clic y arrastrá o teclas)
5. Dispará por turnos. Usá poderes limitados.

### Barcos
- Portaaviones (5)
- Acorazado (4)
- Crucero (3)
- Submarino (3)
- Destructor (2)
